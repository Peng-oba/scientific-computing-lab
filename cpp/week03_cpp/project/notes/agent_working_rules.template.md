# 项目协作约定模板

这是学习用模板。先按自己的真实项目核对路径和要求，再作为任务上下文使用；也可把适用内容合并到已有项目的 AGENTS.md，不直接覆盖现有规则。

- 先读取本次任务卡，说明关键数学/接口约定及不确定处。
- 从任务相关文件开始导航，按证据扩展范围；不要凭名称编造路径。
- 记录源码基线与工作区状态，保持改动与本次任务相关。
- 常规实现和已明确的验证可连续完成，不逐条等待确认。
- 对本教学项目，输入为总应变，更新覆盖旧应力，非法输入保持状态。
- 测试的参考值与容差需要依据；不能为通过测试而擅自改变验收条件。
- 构建使用 project 下独立目录，核对运行的二进制。
- 普通 CTest 四个用例；使用 --no-tests=error，报告实际选择数量。
- 已知故障的修复应保留相同用例的红→绿证据。
- 调试假设包含能否决它的观测；事实、推测、未知项分开。
- sanitizer 的故障程序与正常测试分开统计，修复后重建重跑。
- 最终提供关键 diff、命令、退出码、实际值/数量，以及未运行项。
- 用户研究代码的约定以真实模型为准，不直接移植教学示例的假设。
